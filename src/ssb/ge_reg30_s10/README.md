# RadMod GE S10 — USB/LSB shared GE tracker + silence gate
Hardware untested. Parent is exact S9, SHA-256 locked. S8 was hardware-confirmed; S9 frequency correction has not been independently hardware-confirmed in the available record. Restore S9 (included), or known S8/Alpha1 as appropriate.

## Findings and implementation
S9 gate accepts only VFO mode 2 (USB); mode 3 (LSB) uses shared GE encoder with USB lookup and old pre-GE -6250 Hz LSB frequency shift. The old phase hook is bypassed by the GE encoder. S10 changes gate edge condition from `mode==2` to `mode>=2` after masking to 2 bits. No new IRQ or DMA transaction, no new SRAM. The phase tracker uses the same virtual positive phase state, with a mode-selected calibrated LUT. LSB index k maps to physical REG70 code 111-k, virtual deviation 1500 - measured physical deviation (Hz); Q16 step feedback uses that value, not USB step values. This is conjugation of the RF trajectory around its own reference rather than a naive inversion of the asymmetric code numbering. USB uses 78 original entries, LSB 42 (111..70). Candidate physical offsets assume S9 USB grid-500 Hz, LSB grid-1000 Hz, inferred from S8's carrier and the S9 +500 Hz correction. The existing LSB tuning shim now subtracts 50 ten-Hz units, retaining the preceding per-BK frequency compensation. No absolute LSB alignment or frequency-grid validation on silicon yet.

88-byte helper in verified FF span 0x08070f60..0x08071000 and 84-byte LSB lookup in FF span 0x080704ac..0x08070500. Original stack use preserved. Table selection reads existing active VFO mode via existing helper once per encoder call; new branch for output mapping, original Q16 tracking math and FIR intact. Startup/fallback command selection is mode-specific (USB 0, LSB 111); shared producer clamp 77 becomes 112 to allow LSB physical indices. Existing DMA IRQ, SRAM FIR and watchdog unchanged. FM/AM/RX not deliberately modified. USB arithmetic command stream unchanged in native reference replay, but additional flash dispatch overhead is unmeasured. Prior producer-starvation regressions make this a hardware bench test rather than a release.

## Verification
BTF roundtrip and patch boundaries checked. Gate assembled separately and binary-matched against S10. Gate instruction interpreter passed 12656 frame/path checks plus 4 repeated 2956-sample traces (USB/LSB, both BK selections). The interpreter models the existing template-copy call, not MCU cycles. Native C fixed-point arithmetic reference (not ARM execution) replayed 110370 actual microphone fixture samples per mode; USB codes equal baseline model for every sample, LSB codes within 70..111. 16k digital silence samples per mode, tail mean RF frequency errors -0.0512 Hz USB and +0.0558 Hz LSB in calibrated model. Synthetic complex input tones 400,1000,2000,2600 Hz show exactly mirrored FFT peaks in 1-Hz resolution model. Speech metrics in simulation.csv use full recordings, ungated RF, 300–2800 Hz bands and a 58us first-order settling approximation. These are not actual RF emissions or comparable to active-speech-only earlier reports. Extreme tone rejection numbers may reflect model numerical floor; not hardware claims.
